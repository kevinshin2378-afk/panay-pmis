🔑 Google Drive API 설정 방법

아래 단계를 따라 Google Cloud Console에서 Client ID를 발급받고 index.html 상단의 값을 교체하세요.

1
Google Cloud Console 접속
console.cloud.google.com → 새 프로젝트 생성 (Panay-PMIS)
2
API 활성화
API 및 서비스 → 라이브러리 → Google Drive API 활성화
3
OAuth 동의 화면 설정
OAuth 동의 화면 → 외부 선택 → 앱 이름 Panay-Agusan PMIS → 저장
4
사용자 인증 정보 생성
사용자 인증 정보 → + 만들기 → OAuth 클라이언트 ID → 웹 애플리케이션 선택
승인된 JavaScript 출처에 추가:
https://kevinshin2378.github.io
http://localhost:8080
5
Client ID / API Key를 코드에 입력
index.html 상단 스크립트에서:
const GDRIVE_CLIENT_ID = '발급받은_Client_ID';
const GDRIVE_API_KEY = '발급받은_API_Key';
💡 API Key는 사용자 인증 정보 → + 만들기 → API 키로 별도 생성합니다. Drive API로 제한 설정을 권장합니다.
