❓ PMIS User Guide

1. Getting Started

Access the system anywhere at kevinshin2378-afk.github.io/panay-pmis and log in with the ID/password issued by the administrator. Use the 👁️ icon to show/hide your password.

2. Menu Overview

GENERALDashboard (project KPIs, D-day, milestones) and General Information
CONTRACT STATUSContract amount, period, parties and payment terms
PROGRESS MANAGEMENTS-Curve (Bi-Weekly official schedule + 3rd MPR actuals), Gantt chart, workforce, site photos
DOCUMENTSDeliverables (16 contract items), Issue Tracker (KTS), official documents, approval
COLLABORATIONNotice board, schedule, File Storage linked to Google Drive
SETTINGSUser management, share link & QR code (Admin only)

3. Uploading Files to an Item

Every deliverable and issue has a 📎 Attach File button.
① Click it → ② open the project Drive folder from the link in the dialog → ③ upload your file there → ④ copy its share link → ⑤ paste the name and link, then click Attach. The file appears under the item and opens directly in Google Drive.

4. Recording a Deliverable Submission

On the Deliverables page, click 📤 Record Submission on the item, enter version (e.g. Rev.7), date, cover-letter number, and update the status (Submitted / Under Review / Approved).

5. Issue Tracker (KTS style)

Register correspondence and tasks with + New Issue. Click a row to expand its history. Status symbols: ▽ In Progress · ● Complete · ✕ Closed. Use ✏️ Add Progress Entry as events occur.

6. Roles

Admin manages users and all data · Manager all functions except user admin · Editor edits progress/documents · Viewer read-only.

Questions? Contact the administrator (kecc_admin).

🔑 Google Drive API Setup Guide

Follow the steps below to obtain a Client ID from Google Cloud Console and replace the values at the top of index.html.

1
Open Google Cloud Console
console.cloud.google.com → Create a new project (Panay-PMIS)
2
Enable API
APIs & Services → Library → Google Drive API Enable
3
Configure OAuth Consent Screen
OAuth consent screen → External → App name Panay-Agusan PMIS → Save
4
Create Credentials
Credentials → + Create → OAuth Client ID → Select Web Application
Add to Authorized JavaScript origins:
https://kevinshin2378.github.io
http://localhost:8080
5
Enter Client ID / API Key in Code
index.html in the script at the top:
const GDRIVE_CLIENT_ID = 'YOUR_CLIENT_ID';
const GDRIVE_API_KEY = 'YOUR_API_KEY';
💡 Create the API Key separately via Credentials → + Create → API Key. Restricting it to the Drive API is recommended.
